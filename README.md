**TrinaxAI is an open-source, local-first AI assistant that keeps inference and user data on their own hardware by default.** It combines a FastAPI backend, React/TypeScript PWA, developer CLI, and a RAG engine for private files and code.

- Hybrid vector + BM25 retrieval, reranking, cited answers, collections, and multi-pass research
- Sandboxed coding agent with workspace confinement and approvals for dangerous actions
- Scoped and revocable device pairing for private features across a local network
- Local memory, voice, vision, attachments, optional web search, and cross-device sync
- Installers and CI for Linux, macOS, and Windows, plus automated releases and CodeQL
- 90+ Python/frontend test files covering the agent, CLI, RAG, security, pairing, state, and services
